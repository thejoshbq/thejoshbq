## 👨🏻‍💻 &nbsp;About Me

I'm a research software engineer at the [Otis Lab](https://www.otis-lab.org) at the Medical University of South Carolina. I build and maintain the software that runs our behavior and imaging experiments, from Arduino firmware up to desktop apps and analysis pipelines. Outside the lab I run my own Linux and network setup, and I'm working toward my CCNA.

### 🔬 Research software

- **[REACHER](https://github.com/Otis-Lab-MUSC/reacher)**: runs mouse behavior experiments from a Python (FastAPI) server that drives Arduino chambers over serial and streams every lever press, lick and reward live over WebSockets. In use at four labs across MUSC and the University of Alabama; on PyPI as [`reacher2p`](https://pypi.org/project/reacher2p/).
- **[Labrynth](https://github.com/Otis-Lab-MUSC/labrynth)**: the React/TypeScript app researchers use to set up and watch those experiments, packaged as Windows, macOS and Linux installers through GitHub Actions.
- **[ROIGBIV](https://github.com/thejoshbq/roigbiv)**: finds individual neurons in two-photon microscope movies with a staged Cellpose + Suite2p detection pipeline, then matches the same cells across recording days.
- **[Axplorer](https://github.com/thejoshbq/axplorer)**: lines up brain activity with behavior (peri-event ΔF/F and z-scores) and turns it into figures in a FastAPI + React dashboard.
- **[Phoxel Workbench](https://thejoshbq.github.io/phoxel-workbench/)**: one page that ties the whole toolset together, from rig hardware to final figure.

### 🤖 Agents and infrastructure

- **[Revisionist](https://github.com/kedartech/revisionist)**: a multiplayer alternate-history strategy game where an AI game master runs the world and a deterministic Python referee settles outcomes. AI coding agents write most of the code; I plan the work, set the rules they build under, and review what lands.
- I run a small team of AI agents on my own Linux server: systemd-scheduled jobs with delivery checks, a Git-backed knowledge base with commit hooks that keep each agent in its lane, and review gates before agent-written code merges. A write-up of the tooling and my home network setup is in progress.
